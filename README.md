# Function Board & Sound Board

Download-Seite für zwei kostenlose Windows-Apps:

- **Function Board** – dein digitales Stream Deck: Programme, Websites, Hotkeys und Textbausteine auf Knopfdruck.
- **Sound Board** – Lautstärke pro App, wie an einem Mischpult.

👉 **[Zur Website](https://leocrime271-create.github.io/function-board/)**
